# LifeLink — Organ Donation & Transplant Coordination

## Files
- `index.html` — website structure
- `style.css` — styling and responsive layout
- `script.js` — demo interactions and sample records
- `README.md` — setup instructions

## Run the website
1. Keep all four files in the same folder.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Important
This is a student-project front-end prototype with fictional sample data. It has no backend, database, real authentication, or clinical matching engine. Do not enter real patient or donor information. Matching percentages are illustrative only and must not be used for medical decisions.
